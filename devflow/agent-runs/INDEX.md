# Agent runs — Index

**Methodology version:** 5.2

Agent-run records (`ARUN-YYMMDD-HHmm-<description>.md`), one per agent run
(§2.18): operational narratives — no approval, no manifest, no status, never
governed input (G28). **The next run number (`run: N`) is claimed here**
(§5.15): add the new row before the record is opened, numbered after the
highest run below. A number once claimed is never reused.
